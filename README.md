# Нарезки со стримов Twitch

Даёшь ссылку на запись стрима, а Claude Code делает из неё вертикальные клипы 9:16 для Reels и TikTok: сверху камера, снизу то, что на экране, плашка Twitch с ником и субтитры. Перед монтажом Claude показывает список моментов и ждёт твоего «да».

## 1. Что установить

- **Mac на M1–M4.** На Intel и Windows не работает: распознавание речи идёт через Apple MLX.
- **Homebrew:** https://brew.sh. Вставь команду с сайта в Терминал.
- **Claude Code:** приложение Claude для Mac (вкладка Code) или терминальная версия, см. https://claude.com/claude-code.

Всё остальное (ffmpeg, yt-dlp, Python, Node.js, Whisper, Remotion) Claude установит сам при первом запуске. Это займёт 5–10 минут и около 5 ГБ места. Ещё примерно 2 ГБ скачается при первом распознавании: это модели Whisper и детектора смеха.

## 2. Как скачать проект

- **Без git:** на странице репозитория нажми **Code → Download ZIP**, распакуй, например, в `~/Desktop/twitch-clips`.
- **Через git:**
  ```bash
  git clone https://github.com/<аккаунт>/twitch-clips.git ~/Desktop/twitch-clips
  ```

## 3. Ключ Twitch (нужен для чата)

Чат помогает находить смешные моменты. Без ключа клипы тоже сделаются, только без сигнала чата.

1. В папке проекта скопируй `.env.example` в `.env`. В Finder файлы с точкой скрыты, показать их можно сочетанием `Cmd+Shift+.`. Можно и в Терминале:
   ```bash
   cp .env.example .env
   ```
2. Возьми Client-ID веб-версии Twitch:
   - открой https://www.twitch.tv в Chrome и нажми `Cmd+Option+I`, откроется вкладка разработчика;
   - перейди на вкладку **Network** и в фильтр введи `gql`;
   - обнови страницу (`Cmd+R`) и кликни любой запрос `gql`;
   - в разделе **Headers → Request Headers** найди строку `Client-Id` и скопируй её значение.
3. Впиши его в `.env`: `TWITCH_CLIENT_ID=скопированное_значение`.

Это не пароль и не токен входа: такой же Client-ID есть в браузере у каждого зрителя Twitch. Значения `Authorization` и `OAuth` никуда не вставляй. Client-ID от своего приложения на dev.twitch.tv для скачивания чата, скорее всего, не подойдёт: мы это не проверяли.

## 4. Как открыть в Claude Code

- **Приложение Claude:** вкладка **Code** → выбери папку `twitch-clips`.
- **Терминал:**
  ```bash
  cd ~/Desktop/twitch-clips && claude
  ```

Навык `twitch-clips` подхватится сам. Проверить можно командой `/skills` в терминальной версии или вопросом «какие навыки есть в проекте?».

## 5. Что писать

> сделай нарезки https://www.twitch.tv/videos/1234567890

Или положи запись стрима в папку и напиши: «сделай нарезки из ~/Downloads/stream.mp4».

Дальше:
1. Claude один раз спросит про стиль: музыка, эффекты, начало клипа, склейки.
2. Он скачает и обработает стрим. Для трёх часов это примерно 40–60 минут.
3. Покажет 20 самых громких моментов смеха и таблицу предложенных клипов. **Ответь «да»** или напиши, что убрать или сдвинуть.
4. Смонтирует клипы и покажет итоговую таблицу.

Готовые клипы появятся в папке **`output/`**.

## Настройки

Все настройки лежат в `.claude/skills/twitch-clips/config.json`: ник на плашке, язык стрима, максимальная длина клипа (по умолчанию 2:59), размер и цвет субтитров, автозамены имён. Правила отбора и стиля описаны в `.claude/skills/twitch-clips/style.md`.
